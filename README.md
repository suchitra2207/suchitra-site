# Suchitra Satapathy — personal site

A simple one-page site: hero, about, the book, writing and press, work, contact.
Plain HTML, CSS and JavaScript. No build step.

## Files
- `index.html` — all the content
- `style.css` — colours and fonts are variables at the top (`:root`), taken from the book cover
- `script.js` — mobile menu, portrait fallback, footer year
- `images/` — `book-cover.png`, `book-back.png`, and `suchitra.jpg` (hero), `extraphoto.jpg` (about section)

## Run it
Open `index.html` in a browser.

## Change photos
Replace `images/suchitra.jpg` (hero) or `images/extraphoto.jpg` (about) with new files of the same name. Portrait orientation works best.

## Edit the text
Everything is in `index.html`. The about section sits under `id="about"`.

## Publish for free
Upload the folder to Netlify Drop, Vercel, or GitHub Pages.
